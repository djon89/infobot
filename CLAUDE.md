# InfoBot — правила для работы с проектом

- Владелец бота не программист. Отвечать ему по-русски, простыми шагами, без терминала, если можно обойтись.
- Сервер сам подтягивает `main` из GitHub каждые 2 минуты (`deploy/autoupdate.sh`). Push в `main` = деплой.
  Пушить только код, у которого прошли тесты: `pytest -q`.
- **Каждое изменение поведения бота — новая запись сверху в `app/changelog.py`**: поднять версию
  (новая функция → minor, исправление → patch) и описать изменения 1–5 пунктами простым языком
  для пользователя. После деплоя бот сам пришлёт владельцу это описание в Telegram.
- Схема БД создаётся через `create_all`: новые таблицы можно добавлять, новые колонки в существующие —
  нельзя (нужна миграция; пока не подключён Alembic — делать новую таблицу).
- Секреты только в `/opt/infobot/.env` на сервере, никогда в репозитории.
