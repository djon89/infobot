# InfoBot: Telegram-бот, который работает с информацией

Присылаете ссылку на YouTube, бот отвечает:
1. 📄 **файлом с расшифровкой** (`.txt` с таймкодами);
2. 📝 **конспектом** с ключевыми мыслями прямо в сообщении (плюс копия в `.md`);
3. кнопками **⬇️ Скачать** (качество и дорожка по умолчанию, меняются в `/settings`) и **🎚 Выбрать качество**
   (разовый выбор качества и аудиодорожки, если в видео их несколько).

Видео скачивается через yt-dlp. Сервис `bgutil` выдаёт PO-токены, без которых YouTube блокирует серверы.

Файлы до 2 ГБ отправляются через свой сервер Telegram Bot API. Без него лимит — 50 МБ.

Уже отправленный файл повторно приходит мгновенно: бот пересылает его по `file_id`, не скачивая заново.

## Архитектура

```
Telegram ──► bot (aiogram, polling) ──► Redis-очередь (arq) ──► worker ──► YouTube (через прокси)
                 │                                               │
                 └───────────── PostgreSQL ◄─────────────────────┴──► LLM-роутер
                  users / jobs / videos (кэш)                         ├─ владелец → Claude Code (`claude -p`, подписка)
                                                                      └─ остальные → Claude API
```

- **bot** только принимает сообщения, проверяет доступ и лимиты и ставит задачу в очередь, поэтому отвечает мгновенно.
- **worker** делает долгую работу. Воркеры масштабируются отдельно от бота (`max_jobs`, несколько реплик).
- **Кэш по видео:** если ролик уже обрабатывался, расшифровка и конспект берутся из БД. Модель второй раз не вызывается.
- **Провайдеры подключаются как плагины:**
  - `services/transcript/*` — источники расшифровки, объединённые в цепочку;
  - `services/llm/*` — модели.

  Новые фичи (статьи, голосовые, скачивание видео) добавляются как новые задачи воркера и не требуют переделки.

## Запуск на сервере

На чистом сервере Ubuntu 24.04 выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/djon89/infobot/main/install.sh | sudo bash
```

Установщик сам:
- поставит Docker;
- спросит токен бота;
- определит ваш Telegram ID — для этого нужно нажать «Старт» у бота;
- подключит подписку Claude;
- запустит бота.

Повторный запуск той же команды обновляет бота до последней версии.

## Блокировки YouTube

YouTube блокирует IP дата-центров, поэтому с голого VPS субтитры перестанут отдаваться почти сразу.

**Решение:** резидентный прокси. В библиотеку `youtube-transcript-api` встроена поддержка Webshare. Нужен тариф **Residential**, а не «Proxy Server». Субтитры весят килобайты, так что трафика уходит копейки.

Подходит и любой другой резидентный прокси через `GENERIC_PROXY_URL`.

## Что дальше (уже заложено в архитектуру)

| Фича | Как добавить |
|---|---|
| Видео без субтитров | провайдер `yt-dlp` (аудио) + Whisper в `TranscriptChain` |
| Статьи | задача: `trafilatura` → тот же `summarize` |
| Голосовые | задача: скачать voice → Whisper → `summarize` |
| Миграции схемы | Alembic вместо `create_all` |
